## 发现与修复

附件下载失败时，旧版 `-AcceptUpdate` 仍停在“按回车关闭”，无人值守调用无法结束。已发布更新器 1.1.1：交互模式保留提示，无人值守模式返回失败退出。

Windows 实测无效安装目录返回退出码 1，且不等待输入。回归测试保留子进程句柄后读取真实退出码，避免把空 ExitCode 当作成功验证。

## 网络与验证边界

Windows 直连 API 查询与小清单读取成功；附件范围探测在 25 秒内收到约 850 KiB，平均约 34 KiB/s，不能视为大包下载通畅。

临时代理复用 Mac 已运行的本机代理，只监听 Windows 回环地址，不修改系统代理或 TUN。代理出口访问 GitHub API 返回 403，因此组件场景使用先前查询到的具体版本清单地址；附件由 Windows 原生下载。默认版本发现与附件代理下载在不同网络条件下分别验证，不能宣称全部网络组合通过。
